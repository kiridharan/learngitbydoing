## Tech Stack

- **Frontend Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Visualization**: D3.js
- **Styling**: Tailwind CSS + shadcn-ui
- **Routing**: React Router v6
- **State Management**: Zustand (with local storage persistence)

## Getting Started

1. Clone the repository
2. Install dependencies: `npm i` or `pnpm install`
3. Start development server: `npm run dev`
4. Open `http://localhost:5173` in your browser

For detailed setup instructions, see [Setup & Installation](./SETUP.md).

## Key Features

✅ **Interactive D3.js Visualizations** - Visualize Git concepts in action  
✅ **Structured Lesson Plan** - 14 comprehensive lessons organized in 4 modules  
✅ **Progress Tracking** - Track completion status across all lessons  
✅ **State Persistence** - Progress saved to local storage automatically  
✅ **Responsive UI** - Works on desktop, tablet, and mobile  
✅ **Dark Mode Support** - Pre-configured theme support  

## Learning Modules

1. **Git Fundamentals** - Learn the basics of Git (4 lessons)
2. **Branching & Merging** - Master Git branches (3 lessons)
3. **Remote Repositories** - Work with remotes (2 lessons)
4. **Advanced Workflows** - Advanced Git patterns (3 lessons)
